# Triply Acquisition & Ad Campaign System v1.0
**Founder Working Document**  
**Date:** 6 October 2026  
**Stage:** Pre-MVP / Acquisition system design  
**Status:** Organic-first operating system

## 1. Objective
Triply's acquisition system exists to generate **real travelers creating real upcoming trips in concentrated destination/date cohorts**.

We are not optimizing first for followers, likes, reach, impressions, or generic waitlist volume.

The operating chain is:

> **Campaign → Landing Page → Signup → Trip Created → Eligible Supply → Match Potential**

If a campaign gets views but does not improve useful trip supply, it is not successful.

## 2. Growth Principle
Every campaign should answer:
1. Which destination?
2. Which travel window?
3. Which audience?
4. Which message?
5. Which landing page?
6. Which UTM?
7. Which product event should improve?

## 3. Acquisition Strategy
### Phase 1 — Organic-first
Use:
- Instagram Reels
- Instagram carousels
- Reddit/community participation
- SEO destination pages
- founder-led outreach where useful
- travel communities
- free/partnership-based micro-creators

### Phase 2 — Paid validation
Only after organic creative and funnel conversion produce clear winners.

### Phase 3 — Scaled cohort acquisition
Spend only where destination demand exists, onboarding converts, liquidity improves, and match/conversation rates justify growth.

## 8. Reel System
### Reel A — Destination Hook
0–2 sec: Going to Bali this November?  
2–5 sec: What if someone you’d actually want to meet is going the same week?  
5–10 sec: Show destination + date selection.  
10–16 sec: Show matching traveler / overlap.  
16–21 sec: Show match or conversation.  
21–25 sec: Meet before you go.  
25–28 sec: CTA.

### Reel B — Problem / Solution
**Hook:** Dating apps only work once you arrive.  
**Problem:** You’re flying next month. Why wait?  
**Solution:** Triply matches around destination + overlapping dates.  
**CTA:** Add your trip.

### Reel C — Story
Maya is going to Bali Dec 4–12.  
Noah is going Dec 6–10.  
Their dates overlap.  
They match before arrival.  
**CTA:** Meet before you go.

## 9. Reel Rules
Use:
- realistic people
- actual Triply UI
- clear destination/date context
- fast first 2 seconds
- captions
- no long logo intro

Avoid:
- generic travel montages
- fake influencer luxury
- AI-looking faces where possible
- staged romance
- too much text
